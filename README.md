# Bayi Yazılımı API belgesi

[api.bayiyazilimi.com](https://api.bayiyazilimi.com) — Bayi Yazılımı REST API, webhook ve MCP başvuru belgesi.

- `openapi.yaml`: API tanımının tek kaynağı. Çekirdekte uç nokta eklenince ya da değişince burada güncellenir.
- `index.html`: tanımı [Scalar](https://github.com/scalar/scalar) ile gösteren tek sayfa (derleme yok).
- Yayın: GitHub Pages, `main` dalının kökü; alan adı `CNAME` dosyasında.
